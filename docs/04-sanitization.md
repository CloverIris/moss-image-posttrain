# 脱敏说明

本发布包由内部实验工作区脱敏而来。目标是：**保留全部可复现的技术事实，去除一切
可指认到具体机器与个人的标识**。

---

## 1. 替换规则

| 原始信息 | 替换为 | 说明 |
|---|---|---|
| 主机名（含机型后缀） | `GB203-WS` | 工作站代号，仅示意机型 |
| 隧道域名 / 端口 | `train-host` / `<PORT>` | 远程接入信息 |
| 登录用户名 | `<user>` | 全部出现位置 |
| `/home/<user>/...` | `$HOME/...` | Linux 家目录 |
| 代码根目录 | `$CODE_ROOT` | 训练代码所在目录 |
| 训练产物根目录 | `$MOSS_ROOT` | run / cache / datasets |
| 权重目录 | `$MODEL_ROOT` | 基座与奖励模型 |
| 大数据盘挂载点 | `$DATA_DISK` | 独立 NVMe |
| conda 安装前缀 | `$CONDA_PREFIX` | 见 `00-reproduction.md` §3 |
| 本地工作区绝对路径 | `<WORKSPACE>` | Windows 侧打包目录 |
| 数据集暂存盘符 | `<DATASET_STAGING>` | 采集落地目录 |
| 显卡型号 | `GB203（SM120）` / `GB206（SM120）` | **架构代号 + 显存容量** |

## 2. 显卡的表示方式

原文使用消费级型号，本包统一改为"架构代号（SM 版本）+ 显存容量"：

| 原文 | 本包 |
|---|---|
| 4 张消费级 16 GB 卡（具体型号已隐去） | 4 × **GB203（SM120），16 GB GDDR7** |
| 1 张消费级 16 GB 卡（具体型号已隐去） | 1 × **GB206（SM120），16 GB GDDR7** |

> 原始型号到代号的对应表由内部脱敏工具持有，不随包发布。

这样既保留了复现所需的关键约束（**架构世代、SM 版本、显存容量、卡数**），又不再
指认具体商品型号。若要换成 SM90（Hopper）或更高世代的卡，只要显存 ≥16 GB，
第 1 节的显存约束依然成立，主要结论不受影响。

## 3. 保留了什么

以下信息**未**脱敏，因为它们是复现所必需且不指向个人：

- 操作系统版本、内核版本、驱动分支、CUDA 版本；
- CPU 核数、内存容量、磁盘容量与用量；
- 框架与库的精确版本（JAX / flax / optax / torch / transformers / diffusers）；
- 全部超参、随机种子、数据划分规模与哈希策略；
- 全部时间戳（精确到秒）与训练时长；
- run 名称、配置文件名、指标字段名。

## 4. 代码与数据

- `code/`：源码中的绝对路径、用户名、主机名已按上表替换；
  配置模板保留结构，路径字段改为占位符。
- `analysis/`：CSV 与 JSON 中的路径字段已替换，数值未改动。
- 原始日志/权重/数据集**未随包分发**；原始数据包保留了未脱敏的内部路径，
  仅作内部备份，不对外提供。

## 6. 已知限制

- 训练日志中的**时间戳**与**GPU 索引**未脱敏，理论上可对齐到某一台机器；如对
  侧信道有更高要求，建议对时间戳做整体偏移。
- 数据集本身不随包分发，因此不涉及脱敏。
- 报告中的数值（奖励、MSE、耗时）为真实测量值，未做扰动。
