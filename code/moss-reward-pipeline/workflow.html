当前 reward 如何计算

z_model = (raw_score - frozen_mean) / frozen_scale
aesthetic = 0.5 + 0.0822843590404152 × (0.4 z_kawai + 0.4 z_deepghs + 0.2 z_hps)
final_reward = aesthetic + 1.0 × sdg_artifact_penalty

三个美学模型沿用已有固定均值与尺度，避免逐组重新放大噪声。Kawai 使用类别概率的加权和，DeepGHS 使用官方 percentile，HPS 使用 mu。它们的其他输出也保留。

SDG 只对 artifact 扣分：沿用官方空间惩罚图，alpha=0.5，按 importance/100 加权，重叠同类框取最大值，最后取全图均值。misalignment 的框、原因和 importance 留在日志中，但计分系数固定为 0。空结果不扣分；解析失败或截断会停止当前评估阶段，不会补成“零缺陷”。

如何判断 L2 是否太强

L_total = L_ART + 0.01 × mean((v_current − v_base)²)

base 是同一 state、sigma、prompt、CFG 下关闭 LoRA 的 BF16 模型，不是 rollout 的旧策略。L2 对所有有效训练点生效，即使某些 ART 项被 mask。

重点看加权 L2 的输出梯度是否持续大于 ART，同时 cosine 是否为负、抵消是否明显。它提示两个目标在竞争，但输出空间梯度比不等于 LoRA 参数梯度比，不能仅凭一个阈值断定 beta 必须调整。ART 梯度为 0 时比例有 defined 标志；初始零 LoRA 的 L2=0 是正常情况。旧训练没有这些分项，不能用旧曲线确认强弱。
